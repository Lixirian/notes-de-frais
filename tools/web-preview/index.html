📱 Aperçu Android

Lancer :
Sélectionnez un appareil ou démarrez un AVD.

Clic = tap · cliquer-glisser = balayage · la saisie clavier est envoyée à l'appareil (Entrée, Retour arrière, Échap = Retour). L'image est rafraîchie plusieurs fois par seconde via adb : c'est un aperçu fidèle du rendu, pas une vidéo fluide. Sur l'AVD pliable, « Plier / déplier » bascule entre l'écran externe et le grand écran interne : l'app passe alors en deux volets.
